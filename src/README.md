# Random Quote Generator

A small console program I built while learning Java. It picks a random quote from an array and prints it.

Press Enter to get another quote, or type `q` and press Enter to quit.

## How to run

You need a Java JDK installed.

1. Open the project in IntelliJ IDEA.
2. Open `Main.java`.
3. Run the `main` method.

## What I practised

Arrays, loops, methods, and reading input with Scanner.
