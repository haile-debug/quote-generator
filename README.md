# Random Quote Generator

A small console program I built while learning Java. It picks a random quote from an array and prints it.

Press Enter to get another quote, or type `q` and press Enter to quit.

## Features

- Displays a random quote.
- Prevents the same quote from appearing twice in a row.
- Accepts both `q` and `Q` to quit.
- Removes extra spaces from the user's input.
- Automatically closes the Scanner when finished.

## How to run

You need a Java JDK installed.

1. Open the project in IntelliJ IDEA.
2. Open `Main.java`.
3. Run the `main` method.
4. Follow the instructions in the console.

## What I practised

- Storing quotes in an array.

- Generating random numbers with `Random`.
- Reading user input with `Scanner`.
